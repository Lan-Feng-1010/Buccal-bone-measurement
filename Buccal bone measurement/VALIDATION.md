# v0.3.0 验证说明

2026-09-05：33 项测试通过，详细记录见 `TEST_RESULTS.txt`。包括既有的 26 项三维几何测试，以及 7 项三维输入、接口移除、路径搬迁和显示独立性检查。

已覆盖：四个测量高度、轴线到骨外缘距离、各向异性体素及斜 affine、薄骨、无骨、多段骨、视野与搜索范围截断、平台候选和复核语义、二维 NIfTI 输入拒绝、旧二维命令与模块不可用、匿名编号保留、不同工作目录下读取搬迁后的病例，以及改变显示剖面内容不影响三维测量数值。

测试环境：Windows、Python 3.12.14，依赖版本见 `requirements-tested.txt`。使用通用 Python 接口，但本次未在 macOS 或 Linux 实机验证。依赖和分割模型权重不随分享包分发。
