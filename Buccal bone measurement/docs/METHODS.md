# 三维测量定义

设平台中心为 P，朝根方单位轴向为 u。在 h∈{0,2,4,6} mm 处，测量起点为 P+h·u。

牙弓切线 t 去除沿轴分量后得到剖面法线方向 n；颊侧单位方向 b 与 u、n 垂直，其正负由颊侧参考方向确定。测量剖面经过 P，由 u 和 b 张成。四条射线均在此剖面内，并垂直于种植体中轴线。

程序在 NIfTI affine 定义的毫米坐标中，对射线与三维体素单元边界求交。沿射线经过目标种植体及可能的间隙后，寻找骨段和其外侧退出点。距离为从中轴线起点至该外缘的长度；不减种植体半径。没有可用骨段、多骨段、种植体重入、超出视野、搜索范围截断等情况不输出伪数值。

数值来自三维掩膜，不依赖导出的剖面像素图。剖面只是三维体数据的重采样展示：标签用最近邻，灰度背景用线性插值。显示采样间距 0.1 mm 不等于原始影像分辨率，也不参与三维射线距离换算。未使用二维分割网络或人工截图轮廓。

当前仍需可靠的平台、朝根方中轴线和颊侧信息。SVD 位姿仅为候选；缺少确认位姿时返回待复核。多种植体需要明确目标，牙弓拟合默认拒绝外推。程序尚不包含完整的自动牙位确认、可靠的平台自动检测、五维质量评估智能体或临床放行策略。

结果是分割几何测量，不是亚体素解剖真值。薄骨及金属伪影可能使分割偏离真实边缘，需要另外开展临床参考对照验证。合成体模和单元测试只验证实现与定义的一致性。
